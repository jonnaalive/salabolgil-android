# 개인정보와 기록 처리

이 앱은 회원가입이나 자체 서버 없이 동작하는 초기 개발 버전이다.

- 생활 조건, 후보지 이름·주소, 입력한 목적지 좌표, 체험 기록을 앱 내부 저장소에 보관한다.
- 병명, 진료 내용, 연락처, 이메일을 수집하지 않는다.
- 자체 분석 도구나 광고 SDK를 사용하지 않는다.
- 실제 내비 연결을 선택하면 목적지 이름과 좌표를 차량의 Pleos 내비 서비스에 전달한다. 이 서비스의 후속 처리는 차량 내비 제공자의 정책을 따른다.
- 앱의 전체 데이터 삭제 기능 또는 Android 앱 데이터 삭제로 저장한 내용을 지울 수 있다.
- Android 자동 백업은 비활성화했다. 앱 삭제 전 보관할 기록이 있는지 확인한다.

시연 모드의 기본 후보지와 이동시간은 가상 예시다. 실제 장소 정보나 측정 결과가 아니다.
